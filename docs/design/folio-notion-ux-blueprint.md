# Folio: Notion 사용성 청사진

## 제품의 자리

Folio는 Markdown을 배우거나 Obsidian 플러그인을 설정하지 않아도 바로 쓸 수 있는 공용 노트
제품이다. 파일은 사람이 읽을 수 있는 Markdown으로 남기고, 글을 쓰는 순간에는 Notion의 가장
좋은 사용성을 가져온다. 설정 화면을 찾아다니는 대신 커서 자리에서 다음 행동을 발견한다.

> 파일은 단순하게 남고, 쓰는 순간은 자연스럽다.

Notion의 블록 데이터베이스를 복제하지 않는다. Notion을 쉽게 만드는 입력 문법만 가져와
로컬 우선 Markdown 편집기에 맞춘다.

## 지금 가진 것

- `@today`, `@tomorrow`, `@yesterday`로 글의 흐름을 끊지 않고 날짜를 넣는다.
- `/due`로 저장 문법을 직접 쓰지 않고 할 일의 기간을 붙이거나 바꾼다.
- 폴더 트리, 달력, 템플릿, 휴지통, 서식, 백링크, 아웃라인, 그래프, 태그, 읽기 화면이 있다.
- 내용은 독자 포맷이 아니라 평범한 Markdown으로 남는다.

다음 단계는 도구막대를 하나 더 만드는 일이 아니다. 사용자가 타이핑하는 자리에서 기존 기능을
발견하도록 `@`, `/`, `[[`를 하나의 제안 체계로 묶는 일이다.

## 사용 경험 원칙

1. **커서가 명령 화면이다.** `@`, `/`, `[[`를 입력하면 그 문맥에 맞는 다음 행동이 나타난다.
2. **사용자는 뜻을 고르고 Folio가 문법을 쓴다.** 화면에서는 `내일`을 고르고 파일에는
   `2026-09-12` 또는 `📅 2026-09-12`가 남는다.
3. **결과를 언제나 사람이 확인할 수 있다.** Folio가 없어도 파일을 읽고 고칠 수 있다.
4. **키보드와 터치를 같은 길로 본다.** hover나 데스크톱 단축키로만 되는 기능은 미완성이다.
5. **설정보다 쓰면서 배운다.** 빈 줄, 빈 페이지, 제안 메뉴가 사용 중에 제품을 가르친다.

## 입력 문법

### `@`: 이미 의미가 있는 것을 넣는다

`@`를 날짜 전용 자동완성에서 여러 제공자가 함께 쓰는 삽입 메뉴로 키운다.

| 입력 | 결과 |
|---|---|
| `@today`, `@tomorrow`, `@next friday` | 표준 형식의 날짜 |
| `@회의록` | 기존 페이지 링크 |
| `@remind tomorrow 9am` | 현재 위치에 붙는 로컬 알림 |
| `@이름` | 협업 기능이 생긴 뒤 사람 언급 |

결과는 종류별로 묶고 한글과 영문 이름을 모두 검색한다. 첫 릴리스는 날짜와 페이지만 제공해도
되지만, 나중에 알림과 사람을 추가할 때 메뉴를 갈아엎지 않도록 제공자 계약을 먼저 만든다.

### `/`: 만들거나 실행한다

| 묶음 | 첫 명령 |
|---|---|
| 쓰기 | `/text`, `/h1`, `/h2`, `/todo`, `/bullet`, `/quote`, `/code`, `/divider` |
| 정리 | `/link`, `/toc`, `/template`, `/move` |
| 할 일 | `/due`, `/repeat`, `/priority` |

같은 동작을 `/기간`, `/마감`, `/할일` 같은 한글 별칭으로도 찾는다. 현재 커서에서 쓸 수 없는
명령은 숨긴다. 각 결과에는 쉬운 이름, 실행 결과 한 줄, 고정 명령 이름을 보여준다.

### `[[`: 페이지를 연결한다

`[[`를 입력하면 기존 페이지를 찾고, 없으면 새 페이지를 만든다. 링크는 마우스를 올리거나
키보드로 초점을 맞추거나 길게 눌렀을 때 간단한 미리보기를 보여준다. 백링크가 있으면 제목
근처에 `3개 문서에서 언급`처럼 표시해 그래프 패널을 열지 않아도 관계를 발견하게 한다.

## 할 일 경험

파일에는 계속 읽을 수 있는 Markdown이 남는다.

```markdown
- [ ] 제안서 보내기 📅 2026-09-12
```

편집 화면에서는 날짜를 사람이 읽는 말로 보여준다. 할 일 줄에 커서를 두면 `오늘`, `내일`,
`날짜`, `반복`, `더보기`가 작게 나타난다. `/due`를 다시 실행하면 기존 기간을 교체하고,
완료 직후에는 실행 취소를 제공한다. 지난 날짜는 `3일 지남`처럼 읽힌다.

반복과 우선순위는 단일 날짜와 기간이 안정된 다음에 추가한다. 새 표시를 만들더라도 원본
Markdown에서 뜻을 짐작할 수 있어야 한다.

## 첫 사용과 빠른 메모

빈 줄에는 `내용을 입력하거나 '/'로 기능 열기`를 보여준다. 빈 페이지에서는 모달을 띄우지 않고
문서 안에서 `빈 문서`, `템플릿`, `오늘 일지` 중 하나를 고르게 한다.

빠른 메모는 전역 단축키나 모바일 하단 행동 영역에서 작은 입력창으로 열린다. 저장 위치는
`받은 메모`, `할 일`, `오늘 일지`다. 기본값은 받은 메모로 두어 처음부터 폴더 구조를 결정하게
하지 않는다. 정리는 나중에 `/move`로 한다.

## 구현 순서

### A. 하나의 제안 기반

- `@`, `/`, `[[`가 함께 쓰는 제공자 계약을 만든다.
- 메뉴 모양, 정렬, 키보드 이동, 터치, 한글 IME, 취소 동작을 통일한다.
- 텍스트 삽입과 기능 실행을 구분하고 안전한 실행 취소를 제공한다.
- 기존 `@today`와 `/due`를 저장 형식 변경 없이 새 기반으로 옮긴다.

### B. 매일 쓰는 기능

- `@`에서 자연어 날짜와 페이지 언급을 제공한다.
- `[[`에서 페이지 생성과 미리보기를 제공한다.
- 기본 Markdown, 링크, 템플릿, 할 일 동작을 슬래시 메뉴에서 검색한다.
- 기존 Markdown 형식을 보존하며 할 일 날짜를 화면에서 바꾼다.

### C. 처음 쓰는 사람

- 빈 줄과 빈 페이지가 다음 행동을 알려준다.
- 문서 안에서 템플릿을 고른다.
- 받은 메모, 할 일, 오늘 일지로 빠르게 기록한다.
- 모든 핵심 행동을 모바일에서도 같은 수준으로 제공한다.

### D. 공개 릴리스

- Folio 이름과 작업공간 기능을 하나의 공개 앱 산출물로 배포한다.
- 설치, 업그레이드, 롤백, 제거, 기존 볼트 보존을 수명주기 테스트로 확인한다.
- 처음 쓰는 사람이 도움말을 읽지 않고 인수 여정을 마친다.

## 인수 여정

처음 쓰는 사람이 데스크톱과 모바일에서 도움말을 열지 않고 다음을 끝낸다.

1. 빈 작업공간에서 페이지를 만든다.
2. `@today`를 입력하고 기존 페이지를 연결한다.
3. `/todo`로 할 일을 만들고 날짜를 붙이고 바꾸고 완료한 뒤 취소한다.
4. `[[`로 없는 페이지를 만든 뒤 백링크를 따라 돌아온다.
5. 빠른 메모를 받은 메모에 저장한 뒤 폴더로 옮긴다.
6. Folio를 닫았다 다시 열어 같은 Markdown 내용과 할 일 상태를 확인한다.

콘솔 오류, 글자 손실, 중복 입력이 없어야 한다. 터치 기기에서 hover가 필요한 기능도 없어야 한다.

## 이번에 하지 않는 것

- Notion식 데이터베이스, 수식, 속성, 임의 블록 중첩
- 실시간 공동 편집
- 사람 언급, 댓글, 공유 받은함, 서버 푸시 알림
- 마켓플레이스와 제3자 제공자 API
- AI 글쓰기

필요해지면 각각 별도 캠페인으로 다룬다. 지금 처음 쓰는 개인 사용자의 경험을 완성하는 데에는
필요하지 않다.
