# 처음 Folio를 여는 사람이 빈 문서에서 `@`와 `/`만으로 날짜·링크·할 일을 만들고 다시 찾는다

- **기간**: 2026-09-11 ~ (진행 중)
- **참여**: Josh
- **상태**: 진행

## 왜 하나

Folio에는 폴더 트리, 달력, 템플릿, 백링크, 서식, 할 일 기간처럼 일상 노트에 필요한
기능이 이미 있지만, 처음 쓰는 사람은 도움말과 단축키를 알아야 기능을 발견한다. `@today`와
`/due`가 증명한 인라인 입력 방식을 하나의 제품 문법으로 확장해, Markdown을 몰라도 커서 자리에서
기능을 찾고 결과는 계속 읽을 수 있는 파일로 남게 한다.

## 됐다고 할 조건

| # | 목표 | 됐다고 할 조건 (누가·무엇으로) |
|---|---|---|
| 1 | 새 사용자가 입력 흐름 안에서 핵심 기능을 발견한다 | 제품 검수자가 빈 볼트에서 도움말 없이 인수 여정 1~5를 완료한다 |
| 2 | `@`, `/`, `[[`가 한 제품처럼 작동한다 | 브라우저 계약 테스트가 키보드·IME·터치·취소·실행 취소의 공통 동작을 통과한다 |
| 3 | 기존 Markdown과 볼트가 깨지지 않는다 | 업그레이드·롤백·재설치 테스트 전후 파일 해시와 기존 `@today`·`/due` 동작이 보존된다 |
| 4 | 공개 앱으로 배포할 수 있다 | 공개 저장소의 프라이버시·패키지·수명주기 전체 게이트가 통과하고 실제 설치본에서 같은 여정을 재현한다 |

## 범위

- **포함**: 공통 제안 엔진, 날짜·페이지 `@` 제공자, `[[` 링크 생성·미리보기, 검색 가능한
  `/` 명령, 할 일 날짜 조작, 빈 화면 안내, 템플릿 진입, Quick Capture, 모바일 동등성,
  공개 Folio 앱 패키징과 수명주기 검증.
- **제외**: Notion식 데이터베이스·수식·임의 블록 중첩, 실시간 공동편집, AI 작성 기능.
- **넘김**: 사람 멘션·댓글·공유 Inbox·서버 푸시 알림과 제3자 제공자 마켓은 협업 캠페인으로 넘긴다.

## 접근

1. `@`, `/`, `[[`가 함께 쓰는 제안 제공자와 삽입·동작 계약을 먼저 만든다.
2. 기존 `@today`와 `/due`를 새 계약의 첫 제공자로 옮기고, 페이지 연결과 기본 Markdown 명령을
   같은 메뉴 품질로 확장한다.
3. 빈 페이지·템플릿·Quick Capture가 기능을 사용 중에 가르치게 한다.
4. 공개 Folio 패키지에 포함하고 기존 볼트를 보존한 채 설치·업그레이드·롤백·제거를 검증한다.

상세 UX와 단계별 범위는 [Folio Notion UX blueprint](../../design/folio-notion-ux-blueprint.md)가
정본이다.

## 카드

카드 목록·상태·소유자·진행률은 보드가 정본이다.

- 보드: 사내 인프라 저장소의 `folio-notion-ux` 보드가 상태·소유자·진행률의 정본이다.
- 카드 묶음: 입력 경험, 첫 사용, 공개 릴리스. 구현 종류가 아니라 사용자가 얻는 완료 장면으로 나눴다.

## 결정과 근거

| 결정 | 버린 대안 | 왜 |
|---|---|---|
| Notion의 인라인 발견성을 가져온다 | Notion 블록·데이터베이스 전체 복제 | Folio의 Markdown 호환성과 가벼움을 지키면서 초보자 장벽만 낮춘다 |
| 하나의 제공자 계약을 먼저 만든다 | `@today`, `/due` 같은 명령을 계속 독립 추가 | 메뉴 품질·IME·터치·취소 동작이 기능마다 갈라지는 것을 막는다 |
| 협업 기능은 후속으로 둔다 | 첫 릴리스부터 사람 멘션·댓글·알림 서버 구현 | 계정·권한·알림 저장소 없이도 개인 사용성 목표를 완전히 검증할 수 있다 |

## 검증

- 공개 저장소의 앱 로컬 테스트와 `.github/workflows/ci.yml` 전체 워크플로.
- 빈 볼트와 기존 볼트 각각에서 설치·업그레이드·롤백·제거 후 파일 보존 대조.
- Chromium desktop과 mobile viewport에서 인수 여정 전 단계 클릭·키보드 수행, console error 0.
- 한글 IME 조합 중 메뉴가 텍스트를 삼키거나 중복 삽입하지 않는 회귀 테스트.

## 되돌리기 어려운 일

없다. 이 문서와 보드는 계획 산출물이며, 구현도 공개 앱의 버전된 패키지와 기존 수명주기 롤백
계약 안에서 수행한다. 라이브 배포와 기존 사용자 볼트 마이그레이션은 별도 승인 없이 하지 않는다.

## 남은 것 / 블로커

- 실제 카드 착수 전, Folio 워크스페이스 UI 소스가 공개 앱 산출물에 들어오는 최종 소유 경로를
  현재 앱 분리 계약에 맞춰 확인한다.
