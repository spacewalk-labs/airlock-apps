# 처음 Folio를 여는 사람이 기억나는 말로 문서를 찾고 `@`와 `/`로 바로 이어 쓴다

- **기간**: 2026-09-11 ~ (진행 중)
- **참여**: Josh
- **상태**: 진행

## 왜 하나

Folio에는 폴더 트리, 달력, 템플릿, 백링크, 서식, 할 일 기간과 `@날짜`가 이미 있지만,
기존 `Ctrl-K`와 `Navigate: Search Space`의 터치 진입과 제목·본문 결과 품질은 검증되지 않았다.
기존 검색을 기반으로 제목과 본문을 한곳에서 찾는 경험을 먼저 만들고, `/due`가 증명한 인라인
입력 방식을 제품 문법으로 확장한다.

## 됐다고 할 조건

| # | 목표 | 됐다고 할 조건 (누가·무엇으로) |
|---|---|---|
| 1 | 제목을 몰라도 문서를 다시 찾는다 | 제목 일치 4개·본문 낱말 일치 4개·본문 문구 일치 4개로 고정한 12개 질의마다 목표 문서가 상위 3개 안에 나오고 일치 문장과 위치를 결과에서 확인한다 |
| 2 | `@`, `/`, `[[`가 한 제품처럼 작동한다 | 기존 트리거를 보존하며 브라우저 계약 테스트가 키보드·터치·취소·실행 취소와 한글 본문 조합 중 텍스트 보존을 통과한다 |
| 3 | 기존 Markdown과 볼트가 깨지지 않는다 | 업그레이드·롤백·재설치 테스트 전후 파일 해시와 기존 `@today`·`/due` 동작이 보존된다 |
| 4 | 공개 앱으로 배포할 수 있다 | 공개 저장소의 프라이버시·패키지·수명주기 전체 게이트가 통과하고 실제 설치본에서 같은 여정을 재현한다 |

## 범위

- **포함**: 기존 검색 기준선, 제목·본문 통합검색, 결과 문장·위치 미리보기, 최근 수정 문서,
  폴더·날짜·할 일 필터, 공통 제안 엔진, 기존 날짜 `@` 제공자, `[[` 링크 생성·미리보기, 검색 가능한
  `/` 명령, 할 일 날짜 조작, 빈 화면 안내, 템플릿 진입, Quick Capture, 모바일 동등성,
  공개 Folio 앱 패키징과 수명주기 검증.
- **제외**: Notion식 데이터베이스·수식·임의 블록 중첩, 실시간 공동편집, AI 작성 기능,
  메일 작성·수신·발송·메일함 연동, 오타 교정·유사어 검색, 한글 슬래시 별칭·한글 명령 검색.
- **넘김**: 사람 멘션·댓글·공유 Inbox·서버 푸시 알림과 제3자 제공자 마켓은 협업 캠페인으로 넘긴다.

## 접근

1. 기존 `Search Space`의 제목·본문 범위, 결과 순서, 응답시간과 터치 진입을 먼저 잰다.
2. 제목·본문 통합검색과 결과 미리보기, 최근 수정 문서, 필터를 만든다.
3. 기존 `@날짜`는 유지하고, 페이지 연결은 `[[` 하나로 통일한다.
4. `/`가 쓰는 제안 제공자와 삽입·동작 계약을 만들고, `@`와 `[[`는 기존 트리거를 유지한다.
5. 기존 `/due`를 보존하고 기본 Markdown 명령을
   같은 메뉴 품질로 확장한다.
6. 빈 페이지·템플릿·빠른 메모가 기능을 사용 중에 가르치게 한다.
7. 공개 Folio 패키지에 포함하고 기존 볼트를 보존한 채 설치·업그레이드·롤백·제거를 검증한다.

상세 UX와 단계별 범위는 [Folio Notion UX blueprint](../../design/folio-notion-ux-blueprint.md)가
정본이다.

## 카드

카드 목록·상태·소유자·진행률은 보드가 정본이다.

- 보드: 사내 인프라 저장소의 `folio-notion-ux` 보드가 상태·소유자·진행률의 정본이다.
- 카드 묶음: 입력 경험, 첫 사용, 공개 릴리스. 구현 종류가 아니라 사용자가 얻는 완료 장면으로 나눴다.

## 결정과 근거

| 결정 | 버린 대안 | 왜 |
|---|---|---|
| Notion의 인라인 발견성을 가져온다 | Notion 블록·데이터베이스 전체 복제 | Folio의 Markdown 호환성과 가벼움을 지키면서 초보자 장벽만 낮춘다 |
| 기존 트리거와 일관된 동작 계약을 함께 둔다 | 세 문법을 한 제공자 구현으로 합친다 | 실제 파서 제약을 지키면서 키보드·터치·취소와 한글 본문 보존 품질을 맞춘다 |
| 협업 기능은 후속으로 둔다 | 첫 릴리스부터 사람 멘션·댓글·알림 서버 구현 | 계정·권한·알림 저장소 없이도 개인 사용성 목표를 완전히 검증할 수 있다 |

## 검증

- 공개 저장소의 앱 로컬 테스트와 `.github/workflows/ci.yml` 전체 워크플로.
- 빈 볼트와 기존 볼트 각각에서 설치·업그레이드·롤백·제거 후 파일 보존 대조.
- Chromium desktop과 mobile viewport에서 인수 여정 전 단계 클릭·키보드 수행, console error 0.
- 한글 본문 IME 조합 중 메뉴가 텍스트를 삼키거나 중복 삽입하지 않는 회귀 테스트. 한글 명령 검색은 검증하지 않는다.
- 제목 일치 4개·본문 낱말 일치 4개·본문 문구 일치 4개의 고정 질의별 상위 3개 결과를 기록한다.
- 기존 검색의 응답시간은 다음 성능 캠페인의 기준값으로만 기록하며 이번 릴리스 합격선으로 쓰지 않는다.

## 되돌리기 어려운 일

없다. 이 문서와 보드는 계획 산출물이며, 구현도 공개 앱의 버전된 패키지와 기존 수명주기 롤백
계약 안에서 수행한다. 라이브 배포와 기존 사용자 볼트 마이그레이션은 별도 승인 없이 하지 않는다.

  현재 앱 분리 계약에 맞춰 확인한다.
